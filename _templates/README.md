# Templates (not published)

Jekyll ignores folders whose names start with `_` (unless they are configured
collections), so nothing in here is built into the public site.

These are the original demo pages from the Forty theme, kept as copy-paste
references for layouts and components:

| File | What it shows |
|------|---------------|
| `element_source.md` | Every theme element: headings, buttons, forms, tables, grids, boxes |
| `landing.md` | The "landing" layout with alternating image/text spotlights |
| `generic.md` | A plain text page using the `post` layout |
| `all_posts.md` | A page listing every blog post (`allposts` layout) |
| `posts/` | Example blog posts; move a file to `/_posts/` to publish it |

To use one: copy it to the site root (or `_posts/`), change the front matter
and content, and it will be built.
